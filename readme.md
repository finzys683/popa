# popa git

| команда | че делает |
|---------|-----------|
| git add [имя файла] | индексирует и добавляет файлы в зопу ожидания перед публикацией|
| git commit -m "[коментарий изменения]" | сохраняет текущую версию кода, вместе с коменнтарием, на компе
| git push -u origin main | загружает код в репозиторий на гитхабе |
